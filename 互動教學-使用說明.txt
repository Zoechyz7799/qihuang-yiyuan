氣脈陪練 Qi-Pulse · 水墨翻牌卡冊版
========================================
劉看山陪練 + 動作判定 + 真正可翻面的招式卡 + 離線番茄鐘桌寵

【怎麼開（最簡單：雙擊，不用記指令）】
  Mac     ：雙擊「啟動-互動教學版-Mac.command」
            第一次被 macOS 擋下 → 右鍵該檔 →「打開」→ 再點「打開」；
            之後就能直接雙擊（腳本會自己清掉隔離屬性）。
  Windows ：雙擊「Start-Interactive-Windows.bat」

  腳本自動起本機伺服器並開瀏覽器，通常是
  http://127.0.0.1:4719/practice.html（4719 被占用會自動往後找 4720…）。
  首頁（桌寵 / 番茄鐘）：http://127.0.0.1:4719/

  ⚠️ 那個終端機 / PowerShell 視窗要一直開著。
     關掉它 = 關掉伺服器，瀏覽器會顯示
     「127.0.0.1 拒絕連線 / ERR_CONNECTION_REFUSED」。
     這不是程式壞掉，重新雙擊啟動檔就好。

  手動替代：在資料夾內執行 python3 -m http.server 4719 --bind 127.0.0.1
  （不要用 file:// 直接開 html，攝像頭、WASM 與 ES 模組會被瀏覽器擋下。）

【一、靜默陪伴態（首頁）】
  · 角落劉看山桌寵；番茄鐘用牆鐘計時，只要分頁沒關，切去別的分頁也照樣計時。
  · 時間選擇器：25 分 / 45 分 / 10 秒（Demo，路演用）。
  · 預設完全不請求攝像頭、麥克風權限；只有你主動按練習頁的開鏡頭鈕才會問。
  · 到點同時三件事：頁內看山提醒 + 瀏覽器桌面通知（Notification API）
    + 分頁標題閃爍（⏰ 時間到）。
  · 雙擊桌寵 = 立刻觸發到點提醒，決賽展示不用真的等 25 分鐘。
  · 右上「招式卡冊」可隨時看收集進度，點暗卡會直接帶你去練那一式。

────────────────────────────────────────
【二、練習頁】
  · 全站中國風：宣紙底、宋體題簽、朱紅「氣」印與卷軸雙線框；
    只加了一層 css/ink-theme.css，不影響任何既有功能。
  · 頂部中 / EN 切換；可跳過的簡短免責聲明。
  · 「練這一段」或「連續練完整套」；系統優先推薦還沒解鎖卡的段落。
  · 中國風配樂：Web Audio 合成的五聲音階（宮商角徵羽）+ 起/停/收鼓點，
    完全離線、沒有音檔、不碰麥克風。右上「音樂 開／關」可切，狀態會記住。
  · 視覺引導：劉看山官方素材 + 動態黑手臂 + 發光的手手，配合呼吸縮放、
    節奏進度條與鼓點，逐步示範這一式。

  ★ 默認無攝像頭模式：不開鏡頭就照原節奏走完整輪，不會卡在「等待入鏡」。
    想讓看山判定動作，再按「一鍵開啟本地攝像頭」：
      - 開鏡頭後才啟用判定，須穩定保持 1.2 秒才放行，進度條顯示保持進度。
      - 未達標會即時給要點提示（例如「左臂再展開一點」），不會靜止卡住。
      - 「僅跟練（不判定）」隨時可退回純計時跟練，是現場保底。
    40–50cm 即可，不必後退 1 米；頭、雙肩、雙肘清晰入鏡就能判定，
    雙手略伸出畫面仍會以外推座標繼續判定。
  · 練習結束 / 中斷 / 關分頁，會立刻停掉所有媒體軌道（攝像頭綠燈熄滅）
    與音樂排程。
  · 只有在開過鏡頭、且真的讀到關節時，才會顯示參考角度，
    並標註「攝像頭估算，僅供參考」。
  · 英文模式使用 window.speechSynthesis：會自動挑自然女聲
    （macOS 上優先 Samantha，不再抓到第一個 en-US 的 Alex 男聲），
    語速與音高也調亮。切到 EN 後，標題列會出現語音下拉，
    可直接選系統裡任何聲音，並標註「女聲 / 男聲」；選完會試聽一句。

【三、招式卡冊：拿卡流程 + 真正翻牌】
  拿到卡的完整路徑（練習前卡牆上有四步引導）：
    壹 選「武術三式」（現在是預設套路）
    貳 按「開始」練一式（點暗卡或首頁卡冊會自動幫你選好）
    參 練完 → 翻卡入冊
    肆 集齊 3 張 → 自動合成完整卡
  ⚠️ 「易筋經十二勢」是純舒展、不發招式卡；萬一選到它，
     結束頁會明講並給「切到武術三式・去拿卡」一鍵切換。

  · 4 張水墨卡：壹 并步對拳 / 貳 馬步架掌 / 參 弓步推掌 / 合 三式合氣。
    卡面是劉看山打出該式最帥那一下的水墨定格；完整卡有金墨光暈。
  · 拿到的是「一張真的牌」：結果頁與卡冊大圖都是 3D 翻牌。
    正面只有卡圖與中英招式名；點卡片或按「翻到背面」才會翻過來，
    背面依序是【功用】【傳統武術出處】【針對肌群】【核心要點】
    與克制的現代肩頸科普說明，右下有朱紅「氣」印。
  · 未解鎖 = 偏暗的水墨剪影卡背；每做完一招，整冊「墨氣」就亮一檔
    （0/3 → 1/3 → 2/3 → 3/3 全冊點亮），新解鎖的卡由暗漸亮翻開。
  · 結算完全確定性：練那一段就拿那張，練完整套就拿齊 3 張並合成；
    中斷不發卡。沒有隨機抽卡、沒有機率、沒有虛擬金幣。
  · 下載會輸出「你目前看到的那一面」：
      卡面 PNG 1280×800 / 卡背 PNG 800×1200，皆為高清。
    卡冊大圖裡另有「下載卡面 PNG」「下載卡背 PNG」兩顆按鈕。
  · 所有進度只存 localStorage；換瀏覽器 / 清資料會重置。

【四、離線 / 隱私】
  MediaPipe 模型、WASM、劉看山素材、卡面插畫、配樂全部在本機，
  不需要網路、不依賴 CDN，使用 CPU 執行（避免無 WebGL 環境崩潰）。
  中國風主題也是純 CSS，沒有字體或圖片要連網下載。
  攝像頭畫面只在本機取骨骼點，不顯示實景、不上傳、不儲存。
