# 氣脈陪練 / Qi-Pulse

純靜態桌寵番茄鐘 + 伸展練習頁。右下角是劉看山；練習頁默認不開攝像頭，僅在你按下按鈕後才會請求權限。

## 本地靜態伺服器

不需要 Vite。任選一種：

```bash
# Python
python3 -m http.server 4719 --bind 127.0.0.1

# Node (若已安裝)
npx --yes serve -l 4719 .
```

然後打開 <http://127.0.0.1:4719/>（桌寵）或 <http://127.0.0.1:4719/practice.html>（練習）。

可選單元測試：

```bash
node --test tests/*.test.js
```

## 怎麼試

### 階段 1 — 桌寵計時

1. 打開首頁：不應出現攝像頭權限彈窗。
2. 看山從右下角滑入，待機浮動，圖片來自 `public/poses/`。
3. 展開卡片，選 **10 秒**，按開始。到點應有：桌寵揮手+文案、Notification（若允許）、標題閃爍。
4. 雙擊看山可立刻觸發提醒。切換 中 / EN。

### 階段 2 — 練習（無攝像頭）

1. 從首頁「開始練習」進入 `practice.html`。
2. 可跳過免責聲明 → 選「練這一段」或「完整套」→ 開始。
3. 看關鍵幀圓形動畫、進度條、階段與呼吸提示；可中斷或完成。

### 階段 3 — 攝像頭

1. 練習進行中按「一鍵開啟本地攝像頭」。
2. 預覽出現後應有姿勢讀數（MediaPipe）。
3. 結束 / 中斷 / 關閉頁面後媒體軌道必須停止（瀏覽器攝像頭指示熄滅）。

### 階段 4 — 招式卡

1. 完成一輪後看到碎片/完整卡結構、今日時長與中斷次數。
2. `localStorage` 鍵 `qimai-progress` / `qimai-lang` 有寫入；可下載卡片圖片。
